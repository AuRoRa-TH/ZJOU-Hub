## 🌟 网站三大核心模块

本站采用模块化矩阵式架构，提供三大核心学习资源专区：

### 📑 1. 往年期末试卷 (`js/Exam-Resources/`)
- 📐 **《高等数学》**：历年期末统考真题 A/B 卷 PDF 原件。
- 🔢 **《线性代数》**：历年期末统考 A/B/C 卷真题全集。
- ⚡ **《大学物理》**：大学物理 A/B/C 卷期末试卷 PDF。
- 🖥️ **《计算机组成原理》**：历年期末试卷与标准参考答案。
- 🗄️ **《数据库原理及应用》**：期末统考真题网页版与判断题库。
- 🌲 **《数据结构》**：期末统考真题完整题库网页。

### 📦 2. 课程资料 (`js/Subjects-Resources/`)
- 💻 **《操作系统》**：期末复习提纲全集与考前冲刺核心知识点。
- 📊 **《大数据技术与应用》**：平时练习题与期末复习题库。
- 🤖 **《机器学习》**：代码填空、单选/多选/简答题库与表格。
- 🔬 **《大学物理实验》**：各项必做实验标准示范报告 PDF（杨氏模量、分光计、静电场、牛顿环、示波器等）。
- 🌲 **《数据结构》**：阶段测验 1~3 与平时作业 1~10 答案题库全集。

### 🌟 3. 优秀学长案例 (`js/Ivory Tower/`)
- 🏛️ **《考研上岸同济大学》**：浙海大学长 11408 一战 372 分成功上岸 985 同济大学全流程高分经验分享与备考指南 PDF。

## 💡 核心功能与特色

- 🔍 **智能搜索与联想高亮**：支持科目名称、资料标题、关键字即时联想，点击平滑滚动并高亮定位。
- 🌐 **多端自适应**：支持桌面端三列矩阵排版与移动端自适应，适配深浅色与高对比度。
- ⚡ **原件秒开直阅**：PDF 原件与 HTML 题库直接在浏览器中秒开浏览，免去复杂登录。
- 📤 **人人皆可贡献**：全站开源托管，点击右上角即可一键直达 GitHub 仓库参与贡献与上传。

## 🚀 本地运行与部署

本项目为纯静态前端架构，**零后台依赖、零构建步骤**：

```bash
# 1. 克隆本仓库
git clone https://github.com/AuRoRa-TH/ZJOU-Hub.git

# 2. 直接使用任意静态服务器（或双击 index.html）即可运行
# 例如使用 VS Code Live Server 或 npx serve：
npx serve .
```

## 🤝 贡献与提交资料

欢迎各位海大学子参与共建！如有往年试卷、优秀实验报告、大作业或升学就业经验分享：
1. Fork 本仓库；
2. 将文件放入对应目录（`js/Exam-Resources/`、`js/Subjects-Resources/` 或 `js/Ivory Tower/`）；
3. 在 `js/data.js` 中补充对应的条目描述；
4. 提交 Pull Request，感谢您的无私奉献！
