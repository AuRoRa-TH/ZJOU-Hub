## 🚀 本地运行与部署

本项目为纯静态前端架构，**零后台依赖、零构建步骤**：

```bash
# 1. 克隆本仓库
git clone https://github.com/AuRoRa-TH/ZJOU-Hub.git

# 2. 直接使用任意静态服务器（或双击 index.html）即可运行
# 例如使用 VS Code Live Server 或 npx serve：
npx serve .
```
